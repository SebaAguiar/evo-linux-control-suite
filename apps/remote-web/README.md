# EVO Remote Web

Bundle estático mínimo para el servidor remoto.

- Conecta a `/ws` (mismo host/puerto, WS/WSS según protocolo).
- Envía `resync` y un comando de ejemplo (`set_mute` canal 0).
- Muestra `hello`, `snapshot`, `patch`, `ack`, `err` y cambios de `connection`.

Por ahora se sirve desde `evo-remote` (placeholder reemplazado). No requiere build (vanilla HTML/JS).
