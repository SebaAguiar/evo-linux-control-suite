# Security Policy

## Supported Versions

EVO Linux Control Suite is under active development. Security fixes land on the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

**Please do not open a public issue for security problems.**

Report privately through GitHub's [Private Vulnerability Reporting](https://github.com/arsian/evo-linux-control-suite/security/advisories/new) (Security → Report a vulnerability). If you cannot use it, open a minimal public issue asking for a private channel — without disclosing sensitive details.

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce or proof-of-concept.
- The affected component (`evo-daemon`, `evo-desktop`, WebSocket server, ALSA interface, or kernel driver).

You can expect an acknowledgement promptly. We will keep you updated while we investigate and will credit you in the release notes unless you prefer to remain anonymous.
